# Split The Bill — UI Source of Truth

The screenshots in /reference are the authoritative visual reference
for the application's UI.

Do not redesign the interface.

Do not replace the neumorphic design with generic SaaS components.

Do not introduce a different color system.

Do not introduce glassmorphism.

Do not introduce gradients unless they already exist in the references.

## Visual language

- Soft neumorphism
- Light neutral background
- Teal/green primary accent
- Dark charcoal typography
- Rounded cards
- Soft diffused shadows
- Inset controls
- Tactile buttons
- Subtle hover/press animations

## Important principle

The implementation should match the reference screenshots
as closely as reasonably possible.

When there is ambiguity, inspect the reference images first.

The screenshots take priority over generic design conventions.

## Product flow

Landing
→ Upload
→ OCR
→ Review
→ Add People
→ Assign Items
→ Split
→ Share

## Current scope

No authentication.

No dashboard.

No account system.

No billing/subscription.

No persistent user profiles.

The MVP should allow users to split a bill immediately.
