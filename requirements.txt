# Split the Bill — Python Backend Dependencies Notice
#
# The Python FastAPI backend dependencies are located in `backend/requirements.txt`.
#
# To install the Python backend dependencies:
#   cd backend
#   python -m venv .venv
#   .venv\Scripts\activate  (or source .venv/bin/activate on macOS/Linux)
#   pip install -r requirements.txt
#
# To install frontend dependencies (Node.js / npm):
#   npm install
